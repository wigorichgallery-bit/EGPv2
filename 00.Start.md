# Platform Enterprise Governance Platform V2

## PHASE 0 — PREPARE WORKSPACE

### 0.1 Create root folder

>```cmd
>mkdir EGPv2
>cd EGPv2
>```

## PHASE 1 — CREATE SOLUTION

### 1.1 Create solution

>```csharp
>dotnet new sln -n Enterprise.Governance.Platform
>```

Verify:

>```cmd
>dir 
>```

Expected:

> Enterprise.Governance.Platform.sln

## PHASE 2 — CREATE STANDARD FOLDER STRUCTURE

>```cmd
>mkdir src
>cd src
>
>mkdir Core
>mkdir Application
>mkdir Infrastructure
>mkdir Web
>```

Expected:

```bash
src/
 ├── Core
 ├── Application
 ├── Infrastructure
 └── Web
```

## PHASE 10 — REMOVE TEMPLATE CLASS FILES

Run manually in each project:

>```cmd
>del Class1.cs
>```

or using ps command

>```ps
> Get-ChildItem -File -Recurse -Filter "Class1.cs" | Remove-Item -Force
>```

Web:

>```cmd
>del WeatherForecast.cs
>del Program.cs
>```
